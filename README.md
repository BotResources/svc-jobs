# svc-jobs

svc-jobs is the generic Jobs service of the BotResources platform. It is the
shared place where the jobs of the platform are submitted for runners, executed
and recorded. It ships as a container image with a Helm chart, and
`contract-jobs` is the crate that other services import to talk to it.

## Checks

```sh
cargo fmt --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace --lib --bins
```

The end-to-end tests need a reachable PostgreSQL, given by `E2E_PG_ADMIN_URL`
(an admin connection that can create databases and roles), and `nats-server`
on `PATH`:

```sh
E2E_PG_ADMIN_URL=postgres://postgres@localhost:5432/postgres \
  cargo test -p svc-jobs --tests -- --test-threads=1
```
